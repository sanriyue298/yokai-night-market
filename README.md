# 妖怪夜市 · 灯火长明

[安卓浏览器直接游玩](https://sanriyue298.github.io/yokai-night-market/) · 建议竖屏。

用九个摊位，经营十二夜的妖怪夜市。招募、摆摊、升级、换位；酒馆、烧烤、茶铺、商人、巡夜人与灯笼之间会产生不同联动。天气提前公开，营业额可在开市前准确预览。每三夜选择一门持续生效的秘术。三盏长明灯是容错机会。

## 运行

在本目录执行 `python -m http.server 8773 --directory docs`，打开 `http://localhost:8773`。

测试：`node check-game.cjs`。

## 操作

- 点选来客，再点空摊位招募；也支持从来客卡片拖放。
- 拖动已开的摊位，可移动或与另一个摊位交换位置。
- 点选摊位可升级或收摊；三级为名铺。
- 「联动图」显示相邻收益路径，只有上下左右算相邻。
- 未达目标时，开市前会再次提示；不达标会熄灭一盏灯。
- 钱袋扣除目标 30% 的维护费；下一夜补贴 12 铜钱。
- 每次操作自动保存至当前浏览器；不跨浏览器、不跨设备。

## 素材与实现

代码为原创。场景和六种摊位图像由 OpenAI 图像生成工具分别生成，按统一风格简报制作，再编码为 WebP 供网页使用。完整提示词见 `art-direction.json`。原始 PNG 在本地保留；仓库发布经过编码的 WebP。图像素材是 AI 生成的，不冒称人工绘制。

风格目标：克制的靛青、矿物绿、暖灯色；细线条、纸木陶瓷材质；统一浅俯视摊位，清晰角色轮廓。美术概念图不作为整屏假交互背景，所有摊位、按钮、收益与联动均由游戏状态独立呈现。

无第三方游戏源码、广告、付费或跟踪接口；不依赖远程字体。音效为浏览器合成，默认关闭。当前版本不提供离线缓存。

## 已知验证边界

自动规则检查与手机尺寸浏览器检查不能代替实体安卓设备的帧率、触控手感、音频和网络表现测试。当前内容为十二夜的第一版完整流程，角色尚未使用逐帧骨骼动画。
